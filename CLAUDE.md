# Claude Code loader

This folder is a context orchestration engine: a markdown brain
shared by a person, a chat assistant and you.

Before doing anything else, read `CONVENTIONS.md` and follow it. It
says what to read at session start, what to write at session end,
and what never to do.

## If the person is new

Many people using this aren't developers. If
`_global/PROFILE.md` is still mostly `_To be populated_`:

- Offer to fill it in with them, one question at a time.
- Use plain English. Explain any technical word the first time.
- Don't assume they know git, GitHub or the terminal. This folder
  works without them. Only run git if they ask.
- When they say "wrap up", save the files yourself, then tell them
  in one or two lines what you changed.
