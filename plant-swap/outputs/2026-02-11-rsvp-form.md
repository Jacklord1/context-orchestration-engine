# RSVP form — live and syncing to the Sheet

Add an RSVP form to the site so the library gets a reliable
headcount, per DECISIONS 2026-02-10. Handoff:
prompts/2026-02-10-rsvp-form.md.

## Result
- `src/pages/rsvp.astro` added: a Netlify form named `rsvp` with
  fields name, email, swap date, bringing, and newsletter opt-in.
- Swap date dropdown reads from `src/data/swaps.json`, so there's
  no second list to keep in sync.
- Apps Script `onRsvp` bound to the RSVP Sheet appends one row per
  submission to the tab for that date.
- "RSVP" link added to the site header.
